# SG mark — usage

| File | Use |
|---|---|
| `svg/SGMM_mark_green.svg` | **Master.** Byte-identical to the approved trace (99.7% match to the master PNG). Never edit the path data. |
| `svg/SGMM_mark_white.svg`, `svg/SGMM_mark_black.svg` | Same path, `fill` changed only |
| `svg/SGMM_mark_green_on_void.svg` | Same path on a #050807 square |
| `png/SGMM_mark_{green,white,black}_{64,256,512,1024}.png` | Transparent renders (Chromium) |
| `png/SGMM_avatar_{800x800,400x400}.png` | Mark at 56% width, centred on Void — YouTube / X avatars |

Rules: clear space 25% of mark width · min 24 px · green, white or black only · on Void or a Void panel, never straight on busy footage · no glow, gradient, outline, rotation or stretch.

Missing: **vector wordmark lockup** ("SG MIND MATRIX" beside the mark). The approved lockup is raster only and is not in this repo yet; add `APPROVED_wordmark_lockup.png` to `01_brand/_source_originals/`. Never retype the wordmark in another font for logo use.
