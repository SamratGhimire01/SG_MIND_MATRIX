# SG MIND MATRIX — working repo

Faceless, cinematic AI documentary + education channel (YouTube first, X second).
Philosophy **THEN → NOW → NEXT**. Central message: **THE WORLD IS BEING REWRITTEN BY INTELLIGENCE.**

Read first: `01_brand/SGMM_Brand_Bible.md` (look + truth; it wins on appearance) and `01_brand/SGMM_Master_Plan_v2_summary.md` (channel strategy).

## Non-negotiables
- Logo: use `01_brand/logo/svg/SGMM_mark_green.svg` exactly. Recolour only via `fill` (#00E676 / #F2F5F3 / #050807). Never redraw, glow, gradient, outline, rotate or stretch. Always render to PNG and look before shipping.
- Palette only: Matrix Green #00E676 · Void Black #050807 · Signal White #F2F5F3 · Deep Forest #0B3D2E · Archive Amber #FFB547 (+ Fog #7C8A84 for secondary text). Tokens: `01_brand/tokens/`.
- Story code: THEN = amber (Editorial Collage) · NOW = white (Manim-style) · NEXT = green (Flow Field). One act, one style. Titles = International Typographic Style.
- Fonts: Space Grotesk Bold (titles), JetBrains Mono (labels/captions/data).
- One green element per frame. No Matrix code rain, no neon, no CRT, no tech-glow.
- Faceless: no face, no real name, no college lanyard, no personal browser profile, no other creators' watermarks.
- Editorial: every claim sourced; no fabricated stats, screenshots or footage; AI imagery never shown as real history.
- SIGNAL is pre-rig: never call it animation-ready; every video must work without it.
- Motion work: storyboard (3–5 options per scene) before building; first build is a draft; verify the decoded MP4 (H.264, yuv420p, AAC). Keep HTML/JS source beside the MP4.
