**Cost:** about 1,350 characters for all 3 videos (X004 363 · X005 695 · X006 295). The free tier's ~10,000 credits a month cover this about 7 times, including retakes.

**Licence (important):** the **free plan has no commercial licence and needs an ElevenLabs attribution line.** Fine for drafts and for testing a voice. **Before a monetised post**, re-generate on **Starter ($6/month)**, which gives commercial rights for audio made while subscribed. Check the current terms on elevenlabs.io before posting.
**Disclosure:** add "Voice: AI narration (ElevenLabs)" to every description (also covers the free-plan attribution).

## Voice and settings
- **One channel voice for all 3 videos** (consistency builds the brand); only the direction changes.
- Pick from the default **Voice Library** voices (library voices are consented; never clone a real person). Search the library for: *male · narrator · warm · conversational · American or British*. Shortlist to listen to: **Brian** (deep American narrator), **George** (warm British storyteller), **Chris** (casual American). Names in the library change — pick by ear, say each sample's first line.
- **Model:** **Eleven v3** (most expressive; the `[tags]` below work only on v3). If v3 sounds unstable, use **Multilingual v2** and delete the tags.
- **Settings:** Stability **0.40** for X005 (expressive), **0.55** for X004 and X006 · Similarity **0.80** · Style 0 · Speed 1.0.
- **Download:** MP3 is fine (WAV/PCM needs a higher plan).

## How to generate (the build needs one line per clip)
Paste **one line at a time**, generate, download, name the file by line: `X004_L01.mp3`, `X004_L02.mp3` … Re-generate any line until it sounds right; keep only the best one per line. I join them with 2 s gaps and build the video from that.
Put all files in one folder per video and send with LocalSend to `SGMM_Inbox`.
