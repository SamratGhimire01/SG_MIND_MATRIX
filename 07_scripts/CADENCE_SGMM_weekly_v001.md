# SGMM weekly cadence v001 (2 Nov 2026, Samrat's decision)

**Every day: 3 short videos for X** (also usable as YouTube Shorts / Reels).
**Every Saturday: 1 long-form episode on YouTube** (8–15 min), posted 7:45 pm Nepal time.

## The 3 daily X videos (fixed formats, so they are fast)
| Slot | Format | What it is | Length | Default style | Voice |
|---|---|---|---|---|---|
| 1 — morning | **SHIFT** | one thing AI changed: THEN → NOW → NEXT in 3 beats | 20–30 s | Editorial Collage (THEN) / Manim (NOW) / Flow field (NEXT) | yes, ~6 lines |
| 2 — afternoon | **TIP** | one practical AI tip, shown step by step | 15–25 s | Papercraft or Claymation | optional (on-screen text works muted) |
| 3 — evening | **LOG** | build-in-public: what was built/learned today, real screen capture + cards | 15–30 s | Voxel or Build-log cards + real OBS clip | optional |

- Vertical 1080×1920 (X also takes it), captions burned in (most watch muted), SGMM end card every time.
- Rotate styles across the week so the feed doesn't look templated (also keeps clear of YouTube's "inauthentic/repetitive content" rule).
- X post rules: native video, 0–2 hashtags, YouTube link only in the first reply (see `.claude/skills/sgmm-publishing`).

## Saturday long-form
- Topic chosen Monday from the week's best-performing SHIFT video (check X analytics).
- Mon: topic + script · Tue: record voice per chapter · Wed–Thu: render 3–6 segments in the week's chosen styles + film desk footage · Fri: CapCut assembly from the numbered clips + QC · Sat 7:45 pm: post (scheduled), 3 thumbnails.
- Structure: cold open → chapters each THEN/NOW/NEXT → honest section → invitation; chapters in the description.

## Samrat's daily time budget (target once the pipeline is built)
~45–60 min a day: approve 3 scripts (one message), record voice lines on the phone, approve the storyboard grid, post. Claude does ideas, scripts, storyboards, render, captions, posting kits.

## Batching (to make it realistic)
- Sunday: Claude drafts the whole week's 21 X scripts in one go → Samrat approves → records all SHIFT voices in one sitting.
- Render a day ahead, so there is always a buffer.

## Until the pipeline is built
Each video is a separate build (more tokens, more time). Build order: pipeline step 1–3 first, then the 3 formats as reusable templates, then daily output.
